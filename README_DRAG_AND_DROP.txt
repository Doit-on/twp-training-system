คำแนะนำสำหรับการอัปโหลดขึ้น GitHub ด้วยการลากวาง (Drag & Drop)
=============================================================
ไฟล์ทั้งหมดในโฟลเดอร์นี้เป็น Version 1.20.0 (เวอร์ชันล่าสุดที่แก้ปัญหา QR, ค้นหารายชื่อ และปุ่มยกเลิกแล้ว)

ขั้นตอนการนำขึ้น GitHub:
1. เปิดเบราว์เซอร์ไปที่: https://github.com/Doit-on/twp-training-system
2. กดปุ่ม "Add file" แล้วเลือก "Upload files"
3. เลือกไฟล์ทั้งหมดในโฟลเดอร์นี้ (Ctrl+A) แล้ว "ลากไปวาง (Drag & Drop)" ในหน้าเว็บ GitHub
4. เลื่อนลงด้านล่าง กดปุ่มเขียว "Commit changes"
5. รอระบบ GitHub Pages อัปเดตประมาณ 30-60 วินาที

เมื่อเปิดหน้าเว็บ ให้สังเกตป้ายเวอร์ชันสีเขียวสด "v1.20.0" ด้านบน จะทราบได้ทันทีว่าระบบเป็นเวอร์ชันใหม่แล้ว!
