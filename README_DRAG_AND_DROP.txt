================================================================================
คำแนะนำการอัปโหลดไฟล์ขึ้น GitHub ด้วยวิธีลากและวาง (Drag and Drop)
เวอร์ชันระบบ: 1.21.0 (Enterprise Edition)
================================================================================

ไฟล์ทั้งหมดในโฟลเดอร์นี้ได้รับการรวบรวมและจัดโครงสร้างแบบ Root Level ไว้อย่างสมบูรณ์
เพื่อให้ท่านสามารถ "ลากและวาง" (Drag & Drop) ขึ้นบนเว็บไซต์ GitHub ได้ทันที โดยไม่ต้องใช้คำสั่ง Git

ขั้นตอนการอัปโหลด:
1. เปิดเว็บบราวเซอร์ ไปที่ GitHub Repository ของท่าน (หน้าแรกของ Code)
2. คลิกปุ่ม "Add file" (อยู่ใกล้ๆ ปุ่มสีเขียว Code) แล้วเลือก "Upload files"
3. เลือกไฟล์ทั้งหมดที่อยู่ในโฟลเดอร์ FOR_GITHUB_UPLOAD นี้:
   - index.html
   - register.html
   - survey.html
   - 404.html
   - .nojekyll
   - backend_code.gs
   - VERSION
   - MANUAL.md
4. ลากไฟล์ทั้งหมดไปปล่อย (Drop) ในช่องอัปโหลดบนหน้าเว็บ GitHub
5. พิมพ์ข้อความกำกับ เช่น "Release v1.21.0 Enterprise Operations & Audit Governance"
6. กดปุ่มสีเขียว "Commit changes" ด้านล่าง

ระบบ GitHub Pages จะทำการ Build และ Deploy หน้าเว็บเวอร์ชัน 1.21.0 ให้ใช้งานได้ทันทีภายใน 1-2 นาทีครับ
